# 数字分身扫描器与共享工作区实施

## 已确定的产品边界

数字分身保存已接纳知识与证据，扫描器保存输入、执行目标、触发和结果接纳策略。运行记录固定每次执行身份与费用归属；行动建议不直接产生副作用。导航先保留数字分身一个入口，扫描器与运行记录作为二级页；后续扫描器用于其他业务时，可挂入通用自动化入口。

个人与组织共享同时作为目标；费用模式为自带密钥与组织统一额度。平台账单、代付和支付渠道不在该模式中；估算成本不能伪装成供应商实际扣款。组织名作为知识中的人物关系字段，不具备任何组织授权含义。

## 当前已接入的代码

- 扫描器页面复用旧规则及运行身份，明确提供 manual、interval、changes 触发与自动接纳开关，保留旧调用方未传字段时的原设置。
- `runTokenLimit` 是额外单次上限，空缺不另设，0 拒绝新模型调用。它在全局 budgetUnlimited 时仍生效，预留时检查 spent+reserved，不以实际结算前的旧用量判断。限制随 scan-run 冻结；旧累计用量不重置。
- 运行记录增加独立导航；旧 `/sources/runs` 路由仍兼容。
- `ApplicationRuntimeOptions.digitalTwinWorkspace` 接收可信宿主绑定 `{twinId, ownerId, authorize}`。同一 fs 内不同 twinId 使用不同存储，同一组织的不同授权成员可以绑定同一 ownerId。ownerId 是稳定工作区归属，不是当前请求用户。未配置时保留旧 personal/admin 数据。
- authorize 在每次服务访问及扫描预算预留、模型发送授权、结果提交复验路径执行，缓存服务不缓存授权。来源预览也先检查授权。该端口必须由服务端成员与权限系统实现，不能从 RPC 参数或模型结果构造。
- 组织来源 reader、模型连接、Kernel 与文件系统也必须由宿主按工作区授权绑定。仅指定 twinId 不会自动分享其他用户文件或凭据。

## 月度计量已接入

工作区 monthlyTokenLimit 与独立 meter-period/meter-entry 记录已接入现有扫描提取：UTC 自然月，预留与 job、累计预算同事务，失败已知用量仍结算，未知保持 pending，跨月结算到原月份，重复结算不重复增加消费。布局升级到5以阻断旧客户端忽略月额度。支持个人池及宿主绑定组织池；尚无成员分摊、金额估算、价格表、支付或通用 Flow 子调用的逐请求额度控制。

## 后续实施清单（以下未完成部分不能作为现有功能使用）

1. **组织成员与角色接线**：组织目录、成员管理、角色、工作区选择与会话认证映射；将服务端主体绑定为 editor/viewer/operator/admin 等具体能力。当前授权端口是宿主能力边界，还不是完整组织管理功能。
2. **通用执行目标**：Agent/Flow 固定发布修订与签名；工具固定工具 ID、版本；MCP 固定连接与具体工具。复用既有提交、取消、核对和 task handle。新扫描器不得直接绕过 Kernel 调用模型或执行外部副作用。
3. **输入绑定**：直接文本、上传快照、工作区引用、URL、工具结果。绑定资源版本，显式网络与文件授权；URL 抓取由宿主管理重定向、大小、类型和网络可达范围，不把任意 URL 视为读取授权。来源变化按内容身份去重。
4. **统一扫描结果**：校验候选知识、证据引用、行动建议。原始输出与知识接纳分开；共享输出不能扩大来源的可见性，用户纠正和推断要区分。
5. **行动**：建议、待确认、执行中、完成、拒绝、取消、失败、待核对。确认冻结目标、参数及其修订；沿用原操作核对未知回执，不自动重发。共享行动需要明确执行者和授权范围。
6. **周期额度与用量账本**：费用账户、扫描器、成员、组织、每次调用身份分别记录。原始输入/输出/cache token、媒体单位、供应商成本、估算成本分列；未知用量保留待结算。父级汇总不重复计费。预留、结算、调整使用稳定请求身份幂等，实际重试调用可产生独立成本。
7. **周期与并发控制**：周期按配置时区确定边界；账户、成员、扫描器额度同时检查。旧累计 token 作为历史事实保留，不通过改周期字段重置旧账。
8. **完整 UI**：工作区选择；四步创建（输入、执行、触发、结果与额度）；运行前预览；按来源/运行筛选结果；行动批准与费用明细。仅显示真实可用能力，不提供尚未接线的执行器选项。

## 验收边界

验证个人存储隔离、组织同归属共享、错误 owner 拒绝、授权撤回后禁止缓存读取/写入/预览；在扫描发送及结果提交阶段重复验证撤权。预算测试覆盖总额度不限额但单次额度为0、显式清除单次上限、失败不启动模型、实际用量仍结算。组织审批、跨主体来源共享与周期计费必须在各自后续接线完成后增加端到端验收，不能用本次存储测试替代。
