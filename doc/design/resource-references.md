# 文件引用与 Flow 输入标准

## 命名空间

笔记导航和存储统一为 `notes`，不再维护第二个 `minds` 笔记空间。启动时经 VFS 将旧 `/home/admin/minds` 移入 `/home/admin/notes`，保留元数据；先检查所有同名冲突，不覆盖已有文件。迁移可重入，完成后删除空的旧目录。旧 `#/minds/...` 浏览器链接解析到 `#/notes/...`。多用户运行时分别迁移各自的 home，不合并用户数据。

## 引用语法

| 写法 | 语义 |
|---|---|
| `@/path` | 当前项目根；非项目编辑器则是当前导航根 |
| `@//path` | 发起调用的导航根，不随侧栏切换改变 |
| `@notes:/path` | 当前用户笔记导航 |
| `@//项目名称/path` | 在项目导航下，从根定位指定项目的文件 |
| `@"//项目名称/带空格的文件.md"` | 引用含空格的完整路径 |

名称用于输入和展示。宿主解析后冻结导航身份、项目稳定身份及项目内相对路径；同名有歧义必须选择，禁止默默取首项。`//` 不表示操作系统根、所有导航或其他用户；跨导航用显式名称。URL 百分号编码只由链接入口解码一次，引用文本中的 `%` 是普通文件名字符。禁止 `..`、反斜杠及 NUL 穿越边界。

当前项目与导航上下文来自发起操作的编辑器，而不是全局活动侧栏。项目下的会话、收藏、任务等导航虚拟节点不冒充普通文件。引用只授予本次读取所需的权限，不扩大 Agent 的文件挂载权限。

## Flow 调用

`/run 参数1 参数2` 运行当前选择的 Flow；没有当前 Flow 时提示选择，不推断目标。`/flow <名称或ID> 参数1 参数2` 显式选择已发布 Flow。位置参数按声明顺序绑定，剩余字段沿用默认值；具名参数形如 `requirements=@notes:/essay/require.md`。未知、重复、超量参数或类型不符均报错。

文件引用读取 UTF-8 正文，执行前在参数表单中预览、确认。普通 Markdown 链接仍是导航链接，不等同于执行参数。参数表单的“选择内容来源”提供文件搜索（可输入 `notes:关键词`）与标准引用；普通聊天保持各自的附件处理契约。

参数来源包括手填、文件、已完成运行结果、显式执行工具/MCP或其他 Flow。搜索和打开来源列表不执行任何操作；用户显式执行后沿持久执行和审批链取结果。失败不能作为成功结果传给下游，未知接纳只核对原请求。确认后的实际值冻结进本次提交，重试不重新读取文件或重复执行来源。

## 分层

- vfs-core：授权文件视图、挂载、严格路径、读写权限及生命周期；不认识笔记或项目业务。
- app-contracts：引用 DTO、纯语法与命令协议。
- app-core：用户和导航上下文、项目名称解析、授权视图绑定及读取。
- UI：搜索、消歧、来源预览和参数绑定；不自行打开宿主绝对路径。
- Flow：消费冻结参数及通用工具执行，不内置作文等业务。

已实现目录迁移、授权文本读取、新会话与已存在会话的参数表单、`/run` 位置参数和 `/flow` 调用。来源选择器可读取已有成功 Run 的值，也可显式执行工具、MCP 工具或已发布 Flow，再选择其输出。来源执行保留 requestId 并通过只读 Inspect 核对丢失回执，不自动重发；来源运行的审批和进度在 DAG 面板处理。

普通文本参数保留文字语义，不会因为其内容像路径就自动读文件。来源为 UTF-8 文本（最多 2 MiB）；图片与二进制文件继续使用既有 files/images 控件。执行来源会创建独立 Session/Run，在运行列表中可查；关闭来源窗口不取消任务。

## CLI

应用 CLI 与 UI 共用引用解析和用户隔离。例：

```sh
pnpm cli session prepare <session-id> --flow <flow-id> --flow-args '@notes:/essay/require.md @notes:/essay/article.md' --submission-file /tmp/review-call.json
pnpm cli session submit <session-id> --submission-file /tmp/review-call.json
```

`--flow-args` 仅用于应用 Session Flow 调用，与位置正文及 `--params` 互斥；确认/恢复文件保存已读取的参数值。submit/receipt 不重新读来源。离线 YAML/RunDefinition 不隐式访问当前用户导航；工具/MCP 编排继续使用既有显式 Tool 节点，文件引用命名空间需要应用宿主上下文。

## 手工启动与嵌套调用

参数确认、文件选择和来源预览仅属于用户手工启动入口。Agent 调用 Flow、Flow 通过 `builtin.flow` 调用子 Flow 直接传递已准备的实参，不依赖 DOM 或参数弹窗；参数缺失或类型错误返回调用错误。显式声明的人工输入节点、`onMissing: interact` 和工具审批继续遵循既有交互契约，不因新增启动表单而改变。
