## 2. P2-01 Skill 生命周期

### 版本与恢复

冻结单元必须包括来源身份、Skill 定义、正文、关键规则、已读支持文件内容及其摘要、工具绑定、程序版本引用。仅保存 id 或修改时间不够；同名不同来源不能被当作同一版本。Task 输入与 Effect 结果继续保存实际使用的快照，后续编辑不能改写它们。

| 策略/状态 | 目标行为 | 必须拒绝的情况 |
| --- | --- | --- |
| `keep-old` | 当前加载选择继续使用持久旧快照，重开和重试可复核相同摘要 | 快照缺失或损坏；当前来源/工具授权撤销；不能凭旧快照恢复访问权 |
| `require-reload` | 发现版本变化后阻断依赖该 Skill 的新任务，显式重新加载后保存新版本 | 不得在上下文组装时悄悄接受当前文件 |
| drift marker | 保存旧/新摘要、来源、检测时刻和处置状态，UI/CLI 可读 | 不得只写一条进程日志；检测不到版本不能声称无漂移 |

版本策略由可信宿主选择并持久化；Skill 自身指令、模型参数和工具结果不能自行放宽策略。显式 reload 与 unload 都使用现有 Session 操作队列及持久 CAS 边界。重新加载失败保留原持久版本和错误；卸载后重开不恢复旧选择。现有纯 ID 记录没有旧正文，不能伪造 `keep-old` 快照，应明确要求重新加载。旧 Task 已有快照与会话加载表的升级分别处理。

验收覆盖定义正文、compact、支持文件、工具绑定、来源切换各自变化，以及删除/禁用/撤权；分别经过直接聊天、Flow 节点、运行时 `load_skill`、手动面板和进程重开。核对持久摘要、实际模型请求和工具授权，不只断言返回字段。

### 自动委派

`supportsSubagent` 只表示能力，不能隐式授予委派权。宿主先把允许自动委派的 Skill 编译成现有 Flow 委派模板和统一监管组：固定 Skill 版本、角色/模型、输入输出、数量/并发/深度/预算上界、父子工具交集、失败与取消策略。沿用现有 TaskGroup/Flow 调度，不在 kernel-adapters 引入上层依赖或第二套子代理调度器。

必须定义触发的业务输入与稳定请求身份：重复匹配、Effect 重放及恢复不能重复创建子任务；加载索引、列举目录和 UI 刷新不能创建任务。直接聊天与 Flow 均需正式入口；不支持的入口在提交前明确拒绝。action/silent Skill 保留手动语义。验收需要子任务创建前后、子任务完成而父 join 尚未提交时的 SIGKILL，以及父取消/失权后的迟到创建拒绝。

### 生命周期与错误矩阵

对来源扫描、支持文件读取、动态工具注册、身份提交、订阅建立分别注入延迟，与 load/unload、cwd 切换、来源撤销、Session 关闭、运行时销毁/重建交错。旧作用域不能发布到新实例；关闭必须等待已开始操作，拒绝排队操作；不同 Session 不相互阻塞；恢复失败可重试且不能残留部分扩权。

身份写入仅重试 Kernel `CONFLICT`，其他提交前/后错误立即报告。自动加载回滚必须同时保留持久化与清理错误。当前回归入口为 `backend/kernel-adapters/src/skill/loaded-state.test.ts`、`prompt-context.test.ts`、`session-skill-close.test.ts` 与 runtime 测试；这些不替代完整版本和自动委派验收。

## 3. P2-02 跨 Session Memory

采用独立于会话目录的共享 Memory 生命周期，同机同事务存储优先。不要通过给多个调用者伪造同一个 sessionId 或全局 namespace 名绕过 Session 隔离。原 SessionMemoryProvider 保持本地缺省行为；共享必须显式选择资源。

| 契约 | 完成条件 |
| --- | --- |
| 身份 | 稳定共享资源 ID、不可复用的 incarnation、namespace/scope/entryId、单调 revision；记录创建者和本次写入的 Session/Task/Effect 来源 |
| 授权 | 宿主创建/授予/撤销，精确指定 Session 与可读/可写 scope；模型不得提交 actor 或授权策略；读取、检索和写入均在权威边界校验 |
| 并发 | 校验授权、预期版本、修改内容、写审计与幂等回执在一个事务内；同一操作重复返回同一回执；内容删除重建不能通过旧版本条件 |
| 生命周期 | 创建者 Session 删除不隐式删除共享数据；共享资源删除需单独授权，写墓碑并拒绝旧句柄；GC 不误删其他 Session 的资源 |
| 撤权 | 撤权提交后拒绝新的读取/检索/修改；已提交 Task 的历史快照不追溯抹除；缓存和向量索引不得绕过撤权 |
| 审计 | 保存操作身份、可信来源、前后版本、授权变更和删除事实；提供正式查询入口，并定义保留策略 |
| 宿主接线 | Agent 配置、CLI YAML/RunDefinition、直接聊天/Flow、模型工具和管理 UI 使用同一共享引用与授权服务；UI 显示本地/共享及来源 |

共享协议不得声称跨数据库原子性或跨主机可用。若以后支持跨 store，按 [Durable 协议](durable-harness-protocol.md) 的 owner/outbox 模式独立设计，不能复用本地事务结论。

验收用两个真实 Session、两个进程和同一 LocalFS/SQLite：无授权隔离、显式共享、只读/读写差异、撤权与并发写入、重复请求、创建者删除、资源删除重建、提交前后 SIGKILL、重开读取与审计一致性。补 IndexedDB 后端事务测试；跨 Session 同名 namespace 的既有隔离用例必须继续通过。

## 4. P2-03 Memory 管理、检索与压缩

### 条件冲突与真实入口

条目已使用不可复用 revision 作为正式条件，识别“同内容删除重建”；摘要条件继续保留兼容。冲突 UI 保留草稿，并提供读取最新内容、比较与重新提交的明确步骤；默认不无条件覆盖。模型工具返回可识别的冲突与最新版本引用，不能自动转成无条件写。真实 Tauri 操作需覆盖创建、编辑、删除、冲突后人工处理、切 Session 和重开。

真实云模型调用单独记录 Provider/模型、授权 scope、工具请求/回执和重开内容；本地 HTTP mock 的调度证据继续保留。使用隔离验收数据与已有授权凭据，记录中不得包含凭据。无可用云服务时明确保留该验收项。

### 语义检索

**本轮延期（用户明确指定）**：以下保留为后续目标，暂不实施或验收，也不以词项匹配冒充完成。其余 P2 工作不因此延期。

提供显式配置的 embedding 端口与索引，固定模型/维度/规范化及索引版本；向量索引是可重建派生数据。查询先确定授权资源/scope，再检索，返回稳定来源、内容版本、摘要及相关性信息。内容修改、删除、撤权和模型切换使旧索引失效；检索结果最终核对权威版本，不能返回已撤销或已删除内容。外部 embedding 必须经过已配置的服务边界，不能因启用 Memory 自动发送全部历史。

离线向量夹具验证排序、过滤与重建算法；真实 embedding 用固定语义相近但无词项重合的查询验证召回，并保留无关项对照。明确服务失败时是报错还是显式词项降级，不能把词项结果标为语义结果。

### 内容压缩

压缩必须产生新版本摘要及源条目版本/摘要引用，保存所用模型/程序与策略版本。它是持久任务，提交前再次校验来源版本及写授权；并发修改导致冲突，不能覆盖新内容。保留原内容直至摘要提交并满足引用/保留策略；取消、错误或结果不确定均不提前删除来源。容量/时间 prune 仍是独立策略。

验收涵盖压缩前后内容和来源引用、预算、并发写入、撤权、摘要提交前后 SIGKILL，以及失败后原文可读。独立 retention/GC 还须在真实存储事务内故障、同机并发清理和重开核对，不能以服务层 throw 注入替代 SQLite 提交持久性。

## 5. P2-04 文件消费者与平台矩阵

| 消费者 | 正常与拒绝路径 | 持久/可观察结果 |
| --- | --- | --- |
| 浏览/预览 | 授权目录、同名跨 Session、撤权时正在读、旧句柄再次读 | 界面报告失效并刷新；不泄漏其他 Session 或宿主路径 |
| 编辑/保存 | 只读、并发修改、写入故障、撤权后保存、人工重试 | 保留 dirty/草稿；磁盘与显示内容一致；旧句柄不复活 |
| 工具/Bash | 读写授权、路径逃逸、取消/超时、撤权时在途 | Task/Effect 原因、外部停止事实和重开记录可对应 |
| 附件/mention | attachments-only、图片/相对引用、越权来源、撤销/释放 | 不回退全局路径；历史与用户文件权限区分 |
| 生命周期 | configure/disable/release、普通与工作区视图、draining 崩溃 | 先关闭新操作入口再排空；重开需要显式恢复时明确提示 |
| 平台 | IndexedDB 故障、LocalFS/SQLite、Tauri IPC、原生选择器/隔离器缺失 | 每个平台独立列结果与限制；未运行保持未验收 |

每个窗口场景使用正式入口并保留动作、界面、持久记录三段证据。P0 已验收的挂载/只读/撤销场景直接引用；P0 未完成项不重复标成功。旧句柄可通过保持编辑器打开后从正式挂载入口撤销，再尝试保存观察，不要求向产品暴露底层句柄。

每个子项分别记录代码入口、可复现命令、后端/宿主、持久断言与剩余限制，再更新总项勾选。新增 API 同步对应活文档和包说明。样式豁免继续按 [样式清单](../../scripts/style-class-allowlist.txt) 单独消除，不用空 CSS 规则满足检查。
